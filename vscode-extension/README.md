# VS쫀쿠 Workspace Bridge

Private VS Code Workspace Extension used by the VS쫀쿠 Gateway. It binds an
authenticated Bridge only to `127.0.0.1` in the Workspace Extension host.

Required environment variable:

```text
VSJJONKU_BRIDGE_TOKEN=<32-or-more-character-secret>
```

The extension is intentionally not a public Marketplace extension.
